# S.A.M.COMPTA — version « à plat »

Tous les fichiers se mettent **directement à la racine** du dépôt GitHub (aucun dossier) :
index.html, manifest.json, sw.js, icon-48.png, icon-192.png, icon-512.png,
icon-512-maskable.png, apple-touch-icon.png

## Déploiement
Settings → Pages → Deploy from a branch → main / (root).
Adresse : https://VOTRE-COMPTE.github.io/NOM-DU-DEPOT/

Ouvrir le lien dans Chrome → menu ⋮ → « Installer l'application ».
Ensuite l'application fonctionne hors ligne.
